# Owner onboarding recording

[Watch the 33-second walkthrough](flow.mp4).

The recording uses an isolated local shop with a preauthenticated owner session. It starts at the owner's first visit to the workspace; Google consent is outside this recording.

The walkthrough shows the suggested services, per-kilo and per-load pricing, adding a service, removing a default, adding a piece item, removing and restoring Plastic with Undo, entering weight/load limits, saving, and choosing Main Branch shared-device setup. It ends at Access and devices with Main Branch, the device name, and Shared counter tablet prefilled.

Prices and shop details are sample data. No device invitation is created.

The compact redesign uses aligned item rows, section actions and a centered form, with responsive mobile controls and a focused device prompt. See the [desktop](desktop.png), [mobile](mobile.png), [dark mobile](mobile-dark.png) screenshots and [interface review](interface-review.md) for the applied skills and verification.
